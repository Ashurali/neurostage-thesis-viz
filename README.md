# NeuroStage Thesis Visualization

A single-page visualization of key findings from:

> Y.-C. Huang, "NeuroStage: A Stable and Interpretable Multidomain EEG Model for Early Cognitive Decline Detection," M.S. thesis, Inst. Artif. Intell. Innov., Nat. Yang Ming Chiao Tung Univ., Hsinchu, Taiwan, 2025.

## Live site

https://Ashurali.github.io/neurostage-thesis-viz/

## Local preview

Open `index.html` directly in a browser, or run:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.
