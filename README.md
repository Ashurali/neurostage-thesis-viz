# NeuroStage Thesis Visualization

A single-page visualization of key findings from:

> Y.-C. Huang, "NeuroStage: A Stable and Interpretable Multidomain EEG Model for Early Cognitive Decline Detection," M.S. thesis, Inst. Artif. Intell. Innov., Nat. Yang Ming Chiao Tung Univ., Hsinchu, Taiwan, 2025.

## Live site

https://Ashurali.github.io/neurostage-thesis-viz/

## Sections

1. Hero & headline accuracies
2. The problem (dementia projections, MCI window)
3. Dataset & validation protocol
4. System architecture
5. Three feature domains (PSD, Coherence, Microstate)
6. ReliefF feature reduction
7. Two-stage classifier with meta-learner specification
8. Stage-dependent weight shift (key finding #1)
9. SHAP topomaps
10. Microstate D + FPN/DAN finding (key finding #2)
11. Comparison with prior work
12. Future directions
13. Citation
